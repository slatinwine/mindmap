HELP / 帮助

CONCRETE MINDMAP · MANUAL
Tab添加子主题并开始输入
Enter添加同级主题并开始输入
F2 / 双击编辑当前主题文字
Shift+Enter文字内换行
Del / Backspace删除主题（含子分支）
Space折叠 / 展开分支
方向键在分支间移动（上下取最近节点）

Ctrl+C / Ctrl+V复制分支 / 粘贴为当前主题的子分支
Ctrl+D标记 / 取消重点（橙色钢筋标记）
Ctrl+Z / Ctrl+Y撤销 / 重做
Ctrl+S导出 JSON 文件
滚轮 / 拖空白处缩放 / 平移视图
FORMATS：导入支持 JSON（本工具格式）、Markdown 大纲、FreeMind .mm；导出另有 PNG 图像。内容自动保存在浏览器本地。
